# Language Translation Tool

A simple Python-based Language Translation Tool using **Tkinter GUI** and **deep-translator**.  
This project translates text from a source language to a target language, with optional text-to-speech and copy-to-clipboard features.

## Features
- Translate text between languages (supports Google Translator languages)
- Copy translated text to clipboard
- Read translated text aloud using text-to-speech

## Requirements
- Python 3.10+ (tested with 3.14 using deep-translator)
- Libraries:
  - deep-translator
  - pyttsx3
  - pyperclip
  - tkinter (comes with Python)
